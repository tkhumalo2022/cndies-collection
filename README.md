# Cndies Collection

A responsive multi-page e-commerce storefront built for a consumer electronics retail concept.

## Overview

This project explores the practical frontend work behind an online retail experience: product presentation, navigation, responsive layouts, customer-facing information and reusable visual assets.

Rather than being a framework demo, the repository contains a complete multi-page website structure with dedicated pages, styling, JavaScript, product data and supporting assets.

## Features

- Responsive multi-page storefront
- Product catalogue and product-focused layouts
- About and contact pages
- Reusable CSS and JavaScript structure
- Local product data and image assets
- Mobile-focused interface work
- Search-engine verification file

## Technology

- HTML5
- CSS3
- JavaScript
- JSON / structured local data
- PowerShell utility scripts used during asset preparation

## Project structure

The main application currently lives in `cndies collection/` and includes the website pages, CSS, JavaScript, data and assets.

## What I worked on

The project involved translating a retail concept into a usable web experience, organising product content, creating responsive layouts and preparing product imagery for consistent presentation across the storefront.
