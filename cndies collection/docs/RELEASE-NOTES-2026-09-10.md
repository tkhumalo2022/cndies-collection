# Storefront release — 10 September 2026

## Customer-facing changes

- Added Cndie's Assistant for guided iPhone discovery.
- Added budget and condition based recommendations from the live catalogue.
- Added typed model search and direct shop filtering from the assistant.
- Added delivery, warranty and safer payment guidance with WhatsApp escalation.
- Added more consistent Apple-inspired hierarchy, materials, spacing and motion.
- Increased control sizing and focus visibility for accessibility.
- Added reduced-motion fallbacks and calmer card interactions.
- Replaced the homepage bank-account banner on-screen with a safer confirmation message.

## Preserved behavior

- Product catalogue and prices are unchanged.
- Existing WhatsApp number and product enquiry URLs are unchanged.
- Existing page routes remain unchanged.
- Existing hero/product image assets remain in use.
